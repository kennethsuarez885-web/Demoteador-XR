# Demoteador XR

Demoteador XR es un launcher independiente para Minecraft: Java Edition en Windows.

- Minecraft Java 1.21.8
- Compatible con Fabric
- Inicio de sesión mediante Microsoft OAuth
- Verificación de propiedad de Minecraft
- No recopila ni almacena contraseñas
- Proyecto personal y no comercial actualmente en pruebas

Demoteador XR requiere que cada usuario posea una licencia válida de Minecraft: Java Edition.
